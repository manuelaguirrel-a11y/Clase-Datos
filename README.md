# Manuel Aguirre — Portfolio

Personal portfolio website for Manuel Aguirre, an International Finance student at
Universidad de Monterrey (UDEM). Built as a static site: `index.html`, `css/styles.css`,
`js/main.js`, plus assets under `assets/`.

## Running locally

Any static file server works, e.g.:

```
npx http-server -p 8080
```

Then open `http://localhost:8080`.
